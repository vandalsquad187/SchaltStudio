# Roadmap

Geplante und offene Verbesserungen, sortiert nach Nutzen.

## v1.4 – Editor-Komfort & Didaktik

| Thema | Beschreibung | Status |
|---|---|---|
| Undo/Rückgängig | Vollständiger Undo-Stack für Bauteile, Leitungen, Verknüpfungen | 🟡 geplant |
| Kurzschluss-Warnung | Spule direkt L→0 ohne Kontakt melden (rotes Blinken + Toast) | 🟡 geplant |
| Unverdrahtete Ports | Nicht angeschlossene Anschlüsse dezent markieren | 🟡 geplant |
| Sim-Start räumt auf | Störungen/Taster/Schalter beim ▶-Start zurücksetzen | 🟡 geplant |
| Wendeschütz-Beispiel | Reversieren mit zwei Schützen und Gegensprech-Verriegelung | 🟡 geplant |
| Grenzschalter | Rollenschalter, der an einer Zylinderposition automatisch schaltet | 🟡 geplant |
